# خطة مراجعة تطبيق ميتا

فقرة تمهيدية بالعربية تحتوي على مصطلح إنجليزي مثل **Business Verification** وكذلك رمز `instagram_basic` داخل النص.

## أ · قائمة المهام

- [ ] إنشاء **حافظة أعمال ميتا** (Meta Business Suite) التي ستملك التطبيق.
- [ ] التأكد من تطابق **الاسم القانوني والعنوان والهاتف** مع السجل التجاري (بالعربية والإنجليزية).
- [x] إنشاء التطبيق واختيار **App type = Business** — هذا الاختيار نهائي ولا يمكن تغييره.
- [ ] طلب الأذونات `instagram_basic` و `instagram_content_publish` و `instagram_manage_comments`.
  - [ ] مهمة فرعية مع رابط طويل https://developers.facebook.com/docs/permissions/reference/instagram_content_publish
  - [x] مهمة فرعية منتهية

## ب · جدول

| المنصة | البوابة | المسؤول | الحالة | الملاحظات |

| ثريدز | مراجعة التطبيق | الفريق | 🚫 مرفوض | يحتاج تطبيقاً منفصلاً |

## ج · كتلة برمجية

```nginx
# نقاط النهاية التي تبث الرموز — يجب ألا تُخزَّن مؤقتاً
location /api/ai/ {
    proxy_pass http://127.0.0.1:3003;
    proxy_buffering off;                  # تمرير الاستجابة كما تصل
    proxy_read_timeout 300s;
}
```

## د · تنبيه

:::warning{title="لا تخلط المسارات"}
طلب `instagram_business_basic` مع `instagram_basic` يؤدي إلى رفض تلقائي.
:::

> اقتباس بالعربية مع **نص عريض** ورمز `code_token`.
